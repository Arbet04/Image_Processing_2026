# Image Genny — Frontend

หน้าเว็บของระบบ (HTML / CSS / JavaScript ล้วน ไม่มีขั้นตอน build)

```
Browser (หน้าเว็บนี้) → Backend (Flask :5000) → AI Service (FastAPI :8001) → Forge Neo (:7860)
```

หน้าเว็บคุยกับ **Backend เท่านั้น** ไม่ได้ยิงไปที่ AI Service หรือ Forge Neo โดยตรง

## ไฟล์

- `login.html` — หน้าเข้าสู่ระบบ / สมัครสมาชิก (เริ่มใช้งานจากหน้านี้)
- `index.html` — หน้าหลัก: สร้างภาพ, แก้ไขภาพ, คลังภาพของฉัน
- `config.js` — ตั้งค่า `BACKEND_URL` ที่ทั้งสองหน้าใช้ร่วมกัน

ไม่ต้องติดตั้ง package ใดๆ — มีแค่ browser และ web server สำหรับเสิร์ฟไฟล์

### ไฟล์ตั้งค่ากับ Git

- Frontend **ไม่มีไฟล์ `.env`** — ค่าที่ต้องตั้งมีแค่ `BACKEND_URL` ใน `config.js`
- `config.js` **อยู่ใน Git** (ค่าใน repo คือ `http://127.0.0.1:5000`) แก้ในเครื่องตัวเองได้ แต่ **อย่า commit IP ของเครื่องตัวเองขึ้นไป** ไม่งั้นทุกคนที่ pull จะได้ IP นั้นไปด้วย
  ก่อน commit ให้เช็ค `git status` ถ้ามี `config.js` ที่ไม่ได้ตั้งใจแก้ ให้คืนค่าด้วย `git restore Frontend/ai_studio/config.js`
- ถ้าเปิดผ่าน nginx ไม่ต้องแก้ไฟล์นี้ใน repo — แก้สำเนาที่ `C:\image-project\frontend\config.js` แทน (ดู [nginx/README.md](../../nginx/README.md))

## วิธีรัน

มี 2 แบบ เลือกแบบเดียว:

| แบบ | ใช้เมื่อ | ดูที่ |
|---|---|---|
| **ก. Python http.server** | ทดสอบเอง หรือยังไม่ได้ตั้ง nginx | ด้านล่าง |
| **ข. nginx** | ใช้งานจริงแบบหลายเครื่อง (ผู้ใช้เปิดเว็บที่ port 80) | [nginx/README.md](../../nginx/README.md) |

### แบบ ก. Python http.server

**1. เปิด Backend ไว้ก่อน** แล้วเช็คว่าเปิดอยู่จริง:

```powershell
curl.exe http://<IP Backend หรือ 127.0.0.1>:5000/api/health
```

ต้องได้ `"status": "ok"` ถ้าไม่ได้ ให้แก้ที่ Backend ก่อน (ดู [Backend/README.md](../../Backend/README.md))

**2. ตั้ง `BACKEND_URL` ใน `config.js`**

| กรณี | ค่า |
|---|---|
| Backend อยู่เครื่องเดียวกัน | `const BACKEND_URL = 'http://127.0.0.1:5000';` (ค่าเริ่มต้น) |
| Backend อยู่เครื่องอื่น | `const BACKEND_URL = 'http://<IP เครื่อง Backend>:5000';` |
| เปิดผ่าน nginx | `const BACKEND_URL = '';` — ดูแบบ ข. |

ห้ามมี `/` ต่อท้าย

**3. เปิด web server**

```powershell
cd Frontend\ai_studio
py -3 -m http.server 5500
```

ต้องเห็น `Serving HTTP on :: port 5500` เปิด terminal นี้ทิ้งไว้ ปิดด้วย `Ctrl+C`
(ถ้าต้องการให้เครื่องอื่นเปิดหน้าเว็บนี้ด้วย ให้ใช้ `py -3 -m http.server 5500 --bind 0.0.0.0` และเปิด firewall ให้ port 5500)

หรือใช้ **Live Server** ใน VS Code (extension ritwickdey.LiveServer) → คลิกขวาที่ `login.html` → **Open with Live Server**

ห้ามดับเบิลคลิกเปิดไฟล์ตรงๆ (`file://`) — browser รุ่นใหม่อาจบล็อกไม่ให้หน้าเว็บยิงไปหา IP ในวง LAN

**4. เปิด browser** ไปที่ `http://localhost:5500/login.html`

**5. ตรวจว่าใช้ได้**

1. สมัครสมาชิก → เข้าสู่ระบบ → ต้องเข้าหน้าหลักได้ (ถ้าขึ้น "ไม่สามารถเชื่อมต่อเซิร์ฟเวอร์ Backend ได้" ดูตารางปัญหาด้านล่าง)
2. ในหน้าหลัก กด **ทดสอบการเชื่อมต่อ** ต้องขึ้นว่าเชื่อมต่อสำเร็จ (เช็คเฉพาะ Backend)
3. พิมพ์ prompt แล้วกด **สร้างภาพ** → ต้องได้รูป (ครั้งแรกอาจนานเพราะ Forge Neo โหลดโมเดล)

แก้ `config.js` แล้วต้องกด **Ctrl+F5** ใน browser เพื่อโหลดไฟล์ใหม่ (ไม่ต้อง restart web server)

## ฟีเจอร์

### 🔐 เข้าสู่ระบบ / สมัครสมาชิก
- สมัครและเข้าสู่ระบบผ่าน Backend (`/api/auth/register`, `/api/auth/login`)
- login สำเร็จจะได้ JWT token เก็บใน `localStorage` (คีย์ `aistudio_session`) และแนบไปกับทุกคำขอ
- เปิด `index.html` โดยไม่ได้ login จะถูกพากลับไปหน้า `login.html`
- บัญชีผู้ใช้เก็บใน DB ของ Backend — ถ้าเปลี่ยนไปใช้ Backend เครื่องอื่นต้องสมัครใหม่

### ✦ สร้างภาพ (Text-to-Image)
- พิมพ์ prompt เลือกสไตล์ (สมจริง / การ์ตูน / ภาพวาดสี / อนิเมะ) แล้วกดสร้างภาพ
  - ปุ่มสไตล์เป็นแค่ข้อความที่ต่อท้าย prompt **ไม่ได้สลับ checkpoint** ของ Forge Neo
- ตัวเลือกเพิ่มเติม: ขนาดภาพ, Seed, Steps, Negative Prompt
- ตอนนี้เจนได้ครั้งละ 1 รูป (ช่อง "จำนวนภาพ" ถูกล็อกไว้)
- ปุ่ม "ทดสอบการเชื่อมต่อ" เช็คเฉพาะ Backend ไม่ได้เช็ค AI Service / Forge Neo

### 🧽 แก้ไขภาพ
ทำงานใน browser ล้วนๆ ไม่ผ่าน Backend และไม่บันทึกลง DB

- **รีเซ็ต** — กลับเป็นภาพต้นฉบับ
- **ลบ** — แปรงมือ หรือ เลือกอัตโนมัติ (AI, MediaPipe Interactive Segmenter) ส่วนที่ลบจะโปร่งใส
- **ครอป** — ลากเลือกพื้นที่แล้วกดยืนยัน
- **ปรับสี** — ความสว่าง / คอนทราสต์ / ความอิ่มสี และฟิลเตอร์ ขาวดำ / ซีเปีย
- **หมุน** — หมุนซ้าย/ขวา 90° และพลิกซ้าย-ขวา / บน-ล่าง
- ย้อนกลับ (undo) ได้สูงสุด 15 ขั้น และดาวน์โหลดเป็น PNG

### ♡ คลังภาพของฉัน
- กดหัวใจที่รูปเพื่อบันทึก กดซ้ำเพื่อเอาออก
- ตอนนี้เก็บในหน่วยความจำของหน้าเว็บเท่านั้น **รีเฟรชแล้วหาย** (ยังไม่ได้บันทึกลง Backend)

### 🛡️ จัดการผู้ใช้ (เฉพาะผู้ดูแลระบบ)
- เมนู "จัดการผู้ใช้" แสดงเฉพาะบัญชีที่ `role = 'admin'` (ตั้งด้วย `ADMIN_USERNAME` ใน `Backend/.env`)
- ดูรายชื่อผู้ใช้ทั้งหมด พร้อมจำนวนรูป แล้วกด **ระงับ** หรือ **ปลดระงับ**
- บัญชีที่ถูกระงับจะเข้าสู่ระบบและสร้างภาพไม่ได้ทันที แต่บัญชีและรูปไม่ถูกลบ
- ระงับตัวเองหรือผู้ดูแลระบบคนอื่นไม่ได้
- หน้าเว็บถาม Backend ทุกครั้งที่เปิดหน้าว่า role ล่าสุดคืออะไร ถ้าเพิ่งได้สิทธิ์ admin ให้รีเฟรชหน้า

## ปัญหาที่เจอบ่อย

| อาการ | สาเหตุ |
|---|---|
| "ไม่สามารถเชื่อมต่อเซิร์ฟเวอร์ Backend ได้" และ Backend ไม่มี log ขึ้น | `BACKEND_URL` ใน `config.js` ผิด หรือ browser ยังใช้ไฟล์ cache (กด Ctrl+F5) |
| ข้อความเดียวกัน แต่ Backend มี log 500 | Backend error ภายใน — ดู Traceback ใน terminal ของ Backend |
| เจนรูปแล้วได้ 502 พร้อมข้อความ | ดูข้อความต่อท้าย เช่น ต่อ AI Service ไม่ได้ (เช็ค `AI_SERVICE_URL`), Forge Neo ไม่ได้เปิด, คิวเต็ม |
